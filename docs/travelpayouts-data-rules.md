# Travelpayouts: данные рейса vs названия мест

## Только из API (данные карточки / рейса)

Цена, даты, пересадки, авиакомпания, номер рейса, длительность, link, expires_at и т.п.

**Запрещено** подменять или выдумывать эти поля: статические цены, fallback-списки направлений, дефолт «7 дней», вымышленная авиакомпания.

При ошибке API — пустое состояние или ошибка, не заглушки.

## Разрешено дополнительно

- **`iata_catalog.py`** — IATA → название города/страны для UI (API часто отдаёт только коды)
- Приоритет: если API вернул `destination_name` / `origin_name` — используем их, иначе справочник
- Преобразование ввода пользователя (город → IATA для query-параметра)
- Форматирование отображения (даты, ₽, подписи «от»)
- Логотипы авиакомпаний через `pics.avs.io`, если `airline` пришёл из API

## Отображение

Нет данных рейса в API → `—` или скрыть блок. Нет города в справочнике → показываем IATA-код.
